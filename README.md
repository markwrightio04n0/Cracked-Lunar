## 📋 Overview

Lunar Client Alternative is a feature-rich Minecraft client designed to provide an authentic Lunar-like experience with enhanced cosmetics, mod management, and account features. The application delivers seamless gameplay with a familiar interface and extensive customization options.

---

## ✨ Key Features

- Full-featured Minecraft client with custom launcher
- Integrated cosmetics system (cloaks, wings, particles)
- Built-in mod manager with 50+ pre-configured mods
- Account management with multiple profiles
- Seamless server connectivity
- Custom cloaks, wings, and particle effects
- Mod browser and installer with auto-updates
- Quick profile switching

---

| Category | Mods Included |
